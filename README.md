## 💡 Como eu trabalho

- 🔍 **Diagnóstico antes de achismo:** logs, métricas e evidências guiam a solução.
- 🧪 **Escalonar bem é uma habilidade:** erro reproduzido + log isolado + hipótese de causa raiz.
- ⚡ **Performance importa:** query lenta, índice faltando e gargalo de I/O são problemas que eu caço.
- 🤖 **Se repetiu, automatiza:** menos trabalho manual, menos reincidência de chamados.
- 🧱 **Pensar em produção desde o início:** validação antes e depois, rollback e documentação fazem parte da entrega.
